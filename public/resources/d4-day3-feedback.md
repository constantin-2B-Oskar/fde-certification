# Day 3: main feedback, and what changes

Thank you for your feedback on Day 3. Here are the five points that came up most, and what we changed.

## 1. "The exercise instructions could be clearer"

**What we heard:** it was not always clear what each exercise asked for, or what a good answer looked like.

**What changes:** we rewrote the exercise instructions.

## 2. "We need a survival kit for Claude"

**What we heard:** you want a reference to keep using Claude Code well once the week is over.

**What changes:** we added "The Claude Code survival kit" to the Resources page, under "Further reading". It covers how to prompt Claude Code and how to check the quality of the code it writes, and ends with a checklist to use before you say "done".

## 3. "The data was too clean"

**What we heard:** the exercise data had none of the problems you find in a real plant.

**What changes:** from the next sessions on, the data contains traps: the kind of errors and inconsistencies you will meet in the field.

## 4. "The link between the theory and the exercises was not clear enough"

**What we heard:** it was hard to see how the morning's concepts applied in the exercises.

**What changes:** see point 1. The new instructions show which idea from the session each exercise puts into practice.

## 5. "The app-building part"

**What we heard:** the app-building part of the exercise did not work as well as it should.

**What changes:** we changed it in the exercise for the next sessions.
